# Crunchee — Build Plan
*Approved by Faith Oct 31, 2026 ("lets do it"). Map 1: Bakery. Engine: Unity (iOS).*

## How it all fits together

### 1. Engine + project
- Unity (LTS), iOS build target, URP for glossy stylized lighting on mobile
- Repo: `vera-faith/Crunchee` (private, new — separate from Yun / Strive75 / HaloHalo)
- Scenes: `Home` (character + map select), `Bakery`, then one scene per future theme (Desk, Christmas…)
- Everything offline, no backend, no accounts

### 2. The character system
- One rig, 4 skins: Pudding Bunny, Tofu Cub (v3), Peach Jelly Duck (folded wings), Matcha Mochi Bear
- Movement: third-person — virtual joystick/drag to move, tap to jump; camera follows behind + slightly above, exactly like the reference videos
- Squash-and-stretch on the character itself: stretches rising, squashes flat on landing, recovers with a wobble spring
- Characters start as clean primitive-built models (rounded shapes + the locked concept art as the target), materials per character (caramel gloss, frosted tofu satin, bubbly peach jelly = transparency + bubble specks, powdered mochi matte)

### 3. The squishy system (the heart of the game)
Every interactive object is a **Squishy** with two data axes:
- **Base material** — butter, croissant, cake sponge, paw pad, melon, mochi, macaron, chocolate, keyboard key…
  → defines its sound family, squish depth/speed, and particle type
- **Coating** — plain, wax, sugar, honey, nail polish
  → modifies all three: wax adds a crack shell + crackle layer + flake particles, sugar adds crunch + sparkle burst, honey adds stickiness (slower release, drip/string particles, sticky pull sound), nail polish adds a hard glossy shell (sharp tap, high shine, thinner squish)

Landing pipeline (fires in this order, every step):
1. Object deforms (spring physics scale/vertex squish, deepest at contact point)
2. Coating effect plays (crack / sparkle / drip / gloss flash)
3. ASMR sound plays — layered: coating layer + base layer, with pitch/volume micro-variation so repeats never sound identical
4. Particle burst unique to material × coating
5. Haptic pulse matched to material (soft thud vs sharp tap)
6. Character gets its bounce + squash recovery

### 4. ASMR audio
- Produced/recorded-style samples per base × coating combo, stored as an audio table in code (no ripped audio)
- Layered playback (coating on top of base), randomized micro-variation, gentle compression so it sounds close-mic'd
- Keyboard keys are Squishies too: key sinks, springs back, click = coating-specific clack; rows can mix coatings so running across plays varied clicks

### 5. Maps = one really long path (Faith's design, Oct 31 17:59)
A map is a single long path through its themed world. Each step on the path is a new ASMR item with its own squish/effect/sound. The player starts on a plain platform, moves freely in any direction (drag/joystick), and uses an on-screen **jump button** to hop step to step. Falling just returns you to the path near where you were — the path itself is the level, defined as data (a list of steps: material, coating, layers, position) generated by `LevelPath.cs`, so building a new map = writing a new step list.

**First build — the Butter Path (start of the Bakery map):**
10 butter sticks along the path, all wax-coated, **wax layers increase by 1 each step (1 → 10)**:
- Crack sound/effect scales with layers: thicker shell visually, louder/longer crack, more flakes, deeper crack pattern
- After the crack, the character **sinks a bit into the butter**, wobbles, then hops to the next butter
- This teaches the whole game in 10 steps: move, jump, crack, sink, listen to the progression
After the butters, the Bakery path continues with its other items (croissant, donut, macaron, toast, cake…) in the same step-list format.

### 6. Milestones (each one is playable/testable)
- **M1 Greybox** — start platform + free movement + jump button + camera, path of plain blocks. Proves the *feel* of moving.
- **M2 Squish + sound** — the Butter Path: 10 wax butters, layers 1→10, crack + sink + layered sound. Proves the ASMR. (Keyboard test area after.)
- **M3 Bakery art pass** — full materials, lighting, particles, all Bakery sections.
- **M4 Characters** — 4 selectable characters with squash animation.
- **M5 Ship prep** — icon, screenshots, App Store record (name gate: "Crunchee", fallback "Crunchee: ASMR Squish"), TestFlight.
