# Crunchee — handoff notes (Nov 5, 2026)

Read this first if you're picking up this project cold. Everything below is verified state, not a plan.

## What it is
- 3D ASMR squishy game in Unity 6 (6000.6.7f1), Built-in Render Pipeline (NOT URP), iOS target.
- Map 1 "Bakery / Butter Path": one long spiral-staircase path of 10 wax-coated butter sticks around a center cake tower, inside a dreamy pink checkerboard room. Walk-based traversal: one landing per squishy, the wax cracks into uneven plates, the character slowly sinks in. Every step cracks more.
- Player: Pudding Bunny, a glossy jelly pudding bunny built procedurally in code (see below).

## How the game is actually built (important)
- The scene is GENERATED. `Assets/Editor/ButterPathBuilder.cs` builds everything: menu **Crunchee → Build Butter Path Scene** writes `Assets/Scenes/ButterPath.unity`, applies the app icon and the iOS identity (bundle ID, version, build number, team 738KBBGF8K). Do not hand-edit the .unity file; change the builder and rebuild.
- Menu **Crunchee → Build iOS (Xcode project)** exports to `Builds/iOS`. Full shipping pipeline, incl. the two Terminal commands the owner runs herself, is in `SHIPPING.md`.
- Shipping gotchas (all learned the hard way):
  1. Bump the build number in the builder before each upload (currently writes "2").
  2. After every Unity iOS export, add `ITSAppUsesNonExemptEncryption = false` to the exported `Builds/iOS/Info.plist` (Unity doesn't write it).
  3. `~/crunchee-upload/ExportOptions.plist` must contain `destination = upload` or the export silently produces a local IPA and uploads nothing. "EXPORT SUCCEEDED" alone never proves an upload; look for "Upload succeeded" and confirm the build in App Store Connect → TestFlight.
- All textures in `Assets/Textures/` are generated by the builder at build time (the pixel functions in code are the source of truth; the PNGs regenerate).
- All sounds and music are original procedural synth in `Assets/Scripts/Audio/AsmrSynth.cs` — never ripped audio. The background music is an original 16-second music-box loop composed in code.

## Key scripts
- `Assets/Scripts/Core/Squishy.cs` — crack/sink/spring behaviour, plate-gap crack texture drawing, step cracks.
- `Assets/Scripts/Player/PlayerController.cs` — walk glue to squishy tops, jump, eased input (moveSpeed 3.6, turnSpeed 2.6, inputSmooth 4.5 — tuned after "too sensitive" feedback; don't retune casually), fall safety net (y < -5 respawns).
- `Assets/Scripts/Player/BunnyBody.cs` — bunny animation springs: ears flop back on jump / overshoot forward on landing, arms raise in the air, legs swing when walking, body bob/sway, idle breathing.
- `Assets/Scripts/Camera/ThirdPersonFollow.cs` — behind-the-bunny follow camera (yaw chases the bunny's facing).
- `Assets/Scripts/Game/FinishTrigger.cs` — its own file on purpose: a MonoBehaviour class must live in a file of the same name or Unity won't load it.
- `Assets/Scripts/UI/ProgressHud.cs` — the 10 gold pips; counts `Squishy.Cracked`.

## Locked design decisions (owner's calls — don't relitigate)
- The bunny must match the owner's reference image exactly: glossy translucent jelly pudding, HUGE round head, caramel helmet cap with forehead drips, very long wide lop ears with caramel over the top halves and NO pink inner ear, big glossy eyes, tiny pink nose, OPEN smile with tongue, caramel collar with drips, tiny arms/legs, cream tail. Gameplay view is her BACK. Current build (v9, in `BuildPuddingBunny`) is built to that spec.
- Characters are made of food/squishy material, glossy — never fur/plush. Roster of 4: Pudding Bunny (player), Tofu Cub, Peach Jelly Duck, Matcha Mochi Bear (other 3 not built yet).
- Sound model: soft squish is the base; the wax CRACK is the star (louder than the squish). Landing = deep squish, then the crack a beat later (~0.07s).
- 10 progress pips stay. There is deliberately NO finish celebration.
- Future features the owner wants: a giant pressable ASMR keyboard, character select, sugar/honey/nail-polish coating stretches (synth recipes + data already in code, currently unused in the path).

## Known issues from the build 2 playtest (Nov 5, 2026)
1. **Magenta square artifact** on/near the butter surface in phone screenshots — classic failed-texture color. Suspects: the TwinkleDust sparkle particle sprite or a crack decal rendering differently on device than in the editor.
2. The flat golden crack-network patch still reads as *tangled golden straw* up close instead of clean polygonal plates with wide, deep, glossy gaps (reference: large uneven plates, never uniform — real cracked wax/glass is never the same size twice).
3. After cracking, the butter top can read glassy/messy (large overlapping translucent shards).
4. Open question: all 10 pips showed gold in screenshots taken near spawn — either the owner finished the path first (plausible) or pips light early. Unconfirmed either way.
5. Not yet reported by the owner: feel of the ear flop/arms/legs in motion, movement smoothness, spiral spacing, music and overall sound mix.
